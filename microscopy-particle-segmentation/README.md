# Particle Analysis — Computer Vision

This repository contains experiments for **particle/object segmentation and analysis**.

## Structure

```text
particle-analysis/
├── yolo/                 # YOLO detection/segmentation experiments
├── sam/                  # SAM / SAM3 segmentation experiments
├── maskrcnn/             # Mask R-CNN experiments
├── unet/                 # U-Net experiments
└── other/                # Supporting and experimental notebooks
```

The repository is intentionally separated from the anode–cathode distance project so that the two research workflows remain independent.

## Main focus

- Instance segmentation
- Particle segmentation
- Particle feature extraction
- Model comparison
- Computer-vision experiments

> Before making this repository public, check notebooks for datasets, credentials, API tokens, local file paths, and other private information.
